# Антон ТВ 3.0 — Android TV

Новая версия приложения для Android TV: федеральные и региональные каналы,
M3U и Xtream Codes (live), XMLTV-программа, EPG-сетка, поиск, избранное и недавние.
Ориентирована на бюджетные Amlogic S905/S905X (2 GB baseline, 1 GB — облегчённый режим).

## Что нового в 3.0

- **Плеер:** Media3/ExoPlayer, HLS и MPEG-TS, HTTP и multicast `udp://`/`rtp://`,
  `MulticastLock`, HW → HW+ → SW с запоминанием профиля декодера.
- **ABR:** низкий стартовый битрейт, потолок по разрешению экрана, отдельные
  лимиты для 1 GB.
- **Восстановление:** retry с backoff, failover по резервным URL, автоповтор
  при обрыве, понятные сообщения об ошибках.
- **Каталог:** категории, поиск, избранное, недавние, номер канала, скелетон,
  10-foot размеры и safe zone.
- **Источники:** M3U/M3U8, Xtream Codes (только live, без VOD/сериалов/архива),
  несколько XMLTV-источников с gzip и приоритетом, ежедневное обновление через
  WorkManager, EPG-сетка окном ±6 часов.
- **Память:** каталог в `CatalogStore`, без передачи 450 каналов через `Intent`,
  Coil с дисковым кэшем, облегчённые буферы и кэш на 1 GB.

## Установка

1. Скачайте `app/build/outputs/apk/release/AntonTV-3.0.1.apk`.
2. Разрешите установку из неизвестных источников.
3. Установите APK через USB, файловый менеджер или `adb install -r`.

```bash
adb connect <IP_ТЕЛЕВИЗОРА>:5555
adb install -r app/build/outputs/apk/release/AntonTV-3.0.1.apk
```

`applicationId` остался `ru.freetv.app`, поэтому 3.0 ставится поверх 2.4.
Если нужна установка рядом со старой версией, измените `applicationId` в
`app/build.gradle.kts`.

## Источники

- **M3U:** Настройки → «Источник каналов» → M3U, укажите URL.
- **Xtream:** Настройки → «Источник каналов» → Xtream live, укажите host/port,
  логин и пароль. Поддерживаются только live-каналы.
- **EPG:** Настройки → «Источники EPG (XMLTV)…». Можно добавить несколько
  URL, указать приоритет (1 — главный) и gzip. Привязка программ идёт по
  `tvg-id`/`epg_channel_id`, затем по имени канала.

Программа обновляется раз в сутки через WorkManager и вручную кнопкой
«Обновить» в каталоге. Полный XMLTV в память не грузится: в UI попадает окно
±6 часов, на 1 GB — ±3 часа.

## Управление

| Кнопка | Действие |
|---|---|
| OK | открыть канал / показать панель |
| Долгое OK | меню канала |
| ↑ / ↓ | следующий / предыдущий канал |
| ← / MENU | панель плеера |
| INFO | EPG-сетка |
| Цифры | номер канала |
| Назад | скрыть оверлей / выйти |
| Синяя кнопка | качество |

## Сборка

Нужны JDK 17 и Android SDK (platform 34, build-tools 34.0.0).

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleRelease
```

Готовый файл: `app/build/outputs/apk/release/AntonTV-3.0.1.apk`.

Keystore для подписи: `app/freetv-release.jks` (пароль `freetv2026`,
alias `freetv`). Для публикации замените его на свой.

## Ограничения

- Xtream: только live, без VOD, сериалов, catch-up и timeshift.
- «Архив» — только индикатор, если пришёл в метаданных; воспроизведения архива нет.
- Multicast на части боксов/роутеров может быть запрещён — приложение покажет
  понятную ошибку, а не будет циклически перезапускать поток.
- EPG зависит от качества XMLTV: часть нишевых каналов может быть без программы.

Приложение не хранит и не раздаёт видеопотоки: оно воспроизводит ссылки из
выбранного пользователем источника. Права на каналы принадлежат вещателям.
