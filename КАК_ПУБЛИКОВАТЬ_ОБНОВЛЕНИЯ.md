# Как публиковать обновления через GitHub Releases

Приложение умеет самообновляться: в **Настройки → «Проверить обновления»** оно
проверяет GitHub-репозиторий, а при наличии новой версии скачивает APK и
предлагает установить.

## Текущая настройка

- Репозиторий по умолчанию уже вшит в приложение: **`xSEAmon/xseamon-tv`**
  (вводить в настройках не нужно, поле заполнено автоматически).
- Исходный код лежит в ветке `main` этого репозитория.
- Публикация автоматизирована скриптом `publish.sh` (см. ниже).

## Автоматическая публикация (publish.sh)

После сборки новой версии публикация делается одной командой:

```bash
cd AntonTV-3.0
./publish.sh <tag> "<что нового>"
# например:
./publish.sh v36 "Исправил каналы, добавил поиск"
```

Скрипт сам создаёт релиз с указанным тегом и прикрепляет свежий APK.
Токен он читает из `~/.config/antontv/token` (или из переменной `GITHUB_TOKEN`).

## Один раз: создать репозиторий

1. Заведите аккаунт на [github.com](https://github.com) (бесплатно).
2. Создайте **публичный** репозиторий (приватный не подойдёт без токена),
   например `anton-tv`.
3. В настройках приложения на ТВ укажите репозиторий в поле
   **«GitHub-репозиторий (owner/repo)»**, например `ваш_логин/anton-tv`.
   Сохраните.

## Каждый раз при выпуске версии

1. Соберите APK: `./gradlew assembleRelease` →
   `app/build/outputs/apk/release/AntonTV-3.0.5.apk`.
2. На GitHub откройте репозиторий → **Releases** → **Draft a new release**.
3. В поле **Tag** введите номер версии приложения (versionCode). Он виден в
   файле `app/build.gradle.kts` (строка `versionCode`). Например, для 3.0.5 это
   тег **`v35`**. **Важно:** тег должен быть числом (можно с буквой `v` впереди),
   например `v35` или `35`. Названия вида `3.0.5` приложение не поймёт.
4. В поле **Release title** напишите «3.0.5».
5. В **Describe this release** — что нового (этот текст пользователь увидит
   в окне обновления).
6. Перетащите APK в блок «Attach binaries» (или выберите файл).
7. Нажмите **Publish release**.

Готово. На приставке пользователь нажимает «Проверить обновления» — приложение
видит `v35` (или новее), скачивает APK и предлагает установить.

## Как это работает внутри

- Приложение запрашивает `https://api.github.com/repos/{owner}/{repo}/releases/latest`.
- Сравнивает `tag_name` (versionCode) с установленным `versionCode`.
- Если тег больше — берёт первый `.apk`-ассет релиза, скачивает и открывает
  системный экран установки.
- Тихая установка без подтверждения на Android невозможна (только с root).

## Ограничения GitHub API

- Без токена — до 60 запросов в час на IP. Для ручной проверки этого достаточно.
- Репозиторий должен быть публичным.
